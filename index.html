What is the Salesforce Bulk Field XML Generator?

The Salesforce Bulk Field XML Generator is a free, browser-based tool that helps Salesforce admins and developers generate Salesforce fields in bulk. Instead of creating CustomFields one by one in Setup, you can use the interactive form builder to fill in fields one at a time, or upload a CSV of field definitions to generate all XML files at once.

Each field becomes one CustomField metadata file (.field-meta.xml), automatically placed inside the correct force-app/main/default/objects/<ObjectName>/fields/ folder structure — ready to deploy with sf project deploy start or right-click → Deploy Source to Org in VS Code.

Supported field types: Text, Text Area, Long Text Area, Rich Text Area, Number, Currency, Percent, Checkbox, Date, Date/Time, Time, Email, Phone, URL, Picklist, Multi-Select Picklist, Lookup, Master-Detail, Auto Number, Formula, Roll-Up Summary, Geolocation, and Encrypted Text — all 23 standard Salesforce CustomField types, with type-specific options handled automatically.

Common use cases: migrating fields between orgs, scaffolding new objects, recreating fields from a spec sheet, automating field creation during Salesforce data model design, and generating CustomField metadata for source-driven Salesforce DX projects.

Add Fields to the Queue

Build a list of fields across any objects before generating.
  • Field Label, Field Name (API), and Object Name are always required.
  • Type-specific options (Length, Picklist Values, Formula expression, Reference To, etc.) appear automatically when you select a type.
  • Object Name and Type are kept after each add — quickly add multiple fields to the same object without retyping.
  • Use the × button on any queue item to remove it before generating.
