1

Download the CSV Template

Start with our pre-built template containing all supported field types.
2

Fill in Your Field Definitions

Use the format below. Leave unused columns blank.
FieldLabel FieldName Type Length Precision Scale ObjectName PicklistValues ReferenceTo ChildRelationshipName Description
Field_Label_Text cm_fieldName_Text__c text 255 ObjectName__c Sample CSV for Text field
Field_Label_TextAreaLong cm_fieldName_TextAreaLong__c textarea(long) 3 ObjectName__c Sample CSV for Text field Long
Field_Label_Number cm_fieldName_Number__c number 3 ObjectName__c Sample CSV for Number
Field_Label_Currency cm_fieldName_Currency__c currency 0 3 ObjectName__c Sample CSV for Currency
Field_Label_Percent cm_fieldName_Percent__c percent 0 3 ObjectName__c Sample CSV for Percent
Field_Label_Checkbox cm_fieldName_Checkbox__c checkbox ObjectName__c Sample CSV for Checkbox
Field_Label_Picklist cm_fieldName_Picklist__c picklist ObjectName__c picklistValue1,picklistValue2,picklistValue3 Sample CSV for Picklist
Tip: Leave unused cells blank. The generator only reads the columns required by each field Type and ignores the rest.
3

Upload & Generate

Upload your filled CSV and generate XML files.
Please choose a CSV file first.
4

Deploy to Salesforce

Move the generated files into your project, then deploy.

① Place the files in:

force-app/main/default/objects/<ObjectName>/fields/

② Deploy via Salesforce CLI:

sf project deploy start --source-dir force-app --target-org <your-org-alias>
Easy way (VS Code): Right-click the folder/file → Deploy Source to Org
